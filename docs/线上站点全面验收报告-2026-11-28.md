## 3. Bug 清单

### BUG-01 · AI 指路小票文案重复（严重度：低 · 建议修）

- **现象**：AI 数字分身回答命中站内区块后，角色头顶递出的「指路小票」文案为「▶ 去看看去看联系方式」「▶ 去看看去工作经历」等，出现「去看看去看」重复。
- **复现**：打开主页 → 右下角 AI 分身 → 问「怎么联系你？」→ 观察指路小票（或 DOM 中 `.ai-locate-ticket` 文本）。
- **实际**：`▶ 去看看` + `去看联系方式` + `↗邮箱 / 电话 / 约面试` + `×`。
- **预期**：`▶ 去看联系方式 ↗邮箱 / 电话 / 约面试`。
- **根因**（源码证据）：
  - `js/ai-stage-link.js:76` 前缀写死 `'<span class="ai-locate-k">▶ 去看看</span>'`；
  - `js/ai-stage-link.js:44–49` 每条 ROUTES 的 `name` 本身已以「去」开头（`去工作经历` / `去看能力清单` / `去看教育背景` / `去看证书奖项` / `做了 JD 匹配` / `去看联系方式`）；
  - 两者拼接导致「去看看 + 去看XX」重复，覆盖全部 6 条路由。
- **修复建议**（二选一）：
  1. 把前缀改为 `'▶ 指路'` 或 `'▶ 传送'`，保留 name 不变（改动最小）；
  2. 或把 ROUTES 的 name 去掉「去」字前缀，保留「▶ 去看看」前缀。
  推荐方案 1，一行改动、语义更顺。
- **影响**：仅文案观感，不影响跳转功能（点击仍正确滚动到对应区块）。

## 4. 观察项（非 bug，持续关注）

1. **跨标签页主题同步边界**：在 A 标签页的分享卡网页切换主题（写 localStorage）后，不刷新 B 标签页的主页就打开分享弹窗，弹窗卡主题取自 localStorage（新主题），而主页仍是旧主题，出现短暂不一致。**单标签页正常使用不会触发**（同页切换主题会同步写回），无需专门修复；如要严谨，可让主页监听 `storage` 事件同步 `data-theme`。
2. **指路小票触发/展示时机**：compact 面板下问「怎么联系你？」时，指路小票未稳定出现在截图（DOM 曾在另一轮抓到完整文本）。推测是 display 延迟或面板尺寸限制，不影响功能；后续可复核展示条件。

## 5. 已排除的误报（避免误判）

- **noir 主题文字发黑**：jpeg quality 70 截图压缩伪影导致文字看似沉入背景；png 原图确认文字为白/青色，对比度正常，**非 bug**。
- **联系方式区块空白**：滚动到区块间隙时的瞬间截图，继续滚动后邮箱/电话/博客卡片完整显示，**非 bug**。
- **作品集「水合验证（点击）」按钮**：React 迁移的有意自检特性，点击变「✓ 反应已水合」，旁边标注数据源与构建时间，**非 bug**。
- **本地 404 资源**：均为 Pages Functions 接口与 COS 图片在本地无后端/网络环境的限制，线上正常，**非 bug**。
- **微信登录「未配置」**：未配置 AppID/Secret 的预期降级提示，**非 bug**。
