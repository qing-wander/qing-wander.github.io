从流程痛点出发落地

问题

求职时履历散落在简历、证书与聊天记录里，招聘方三分钟只能看到做过什么，看不到怎么做到、结果如何。

方案

把个人档案做成一套内容系统：一份 JSON 是唯一真相源，脚本生成首页、简历与问答知识库，改内容不改代码。

结果

站点持续迭代：网页简历可直接打印为 PDF，数字分身问答基于真实履历作答，所有页面可静态托管，回滚即换一个提交。

02

产品定位

POSITIONING

一个页面该不该有某个功能，先看它服务谁，再看它是否值得维护。

为谁做

招聘方（HR 初筛 3 分钟 / 面试官深挖 10 分钟）与同行。

明确不做

  • 只想看花哨动效、不关心内容可查性的访客

为什么这样取舍：账要算到分毫可查——档案里的每个数字都能回到真实经历。

04

技术选型

STACK & TRADE-OFFS

每个选择都写清代价；没有代价的技术选型，通常意味着没想过。

选择为什么放弃了什么
静态优先纯静态产物可离线托管，GitHub Pages 也能兜底。依赖运行时的动态站点
单一数据源避免首页、简历、问答三处文案漂移。每个页面各写一份文案
边缘函数问答与留言按请求就近处理，无需自建服务器。独立部署的后端服务
原生 JS + Astro/React渐进迁移，老交互脚本零改动桥接。一次性全量重写
脚本校验CI 守住内容与生成物一致性。靠人工核对
05

能力拆解

WHAT IT DOES

六个模块，每个都从「解决什么问题」讲起，最后落到可验证的位置。

数据驱动渲染

解决什么空板块留下占位与编号断档。

怎么实现按数据判空隐藏板块，导航编号按可见项重排。

板块显隐规则在 js/main.js 的 syncSectionLayout。

网页简历

解决什么投递时简历与首页文案容易不一致。

怎么实现与首页同源生成，可直接打印为 PDF。

resume.html 由 scripts/render_resume.mjs 生成。

数字分身问答

解决什么招聘方想深挖细节，但首页放不下。

怎么实现基于真实履历的 RAG 检索增强问答。

问答看板记录空召回与高频问题。

留言墙

解决什么访客反馈没有沉淀。

怎么实现访客留言与站长回复有后台审核。

后台消息页可审核与回复。

分享卡

解决什么转发链接缺少直观预览。

怎么实现数据、主题与二维码实时生成分享宣传卡。

share-card.html 从 site-data 取数实时绘制。

学历核验

解决什么受限材料不能公开裸露。

怎么实现按设备绑定与限时链接访问。

/api/verify-access 签发限时审批链接。

07

难题档案

PROBLEM FILES

三个真正卡住过进度的问题：现象、怎么定位、最后怎么解决、留下了什么。

D-1

多处文案漂移

SYMPTOM · 症状

首页、简历、问答里的经历描述不一致。

DIAGNOSIS · 诊断

三个页面各维护一份文案。

FIX · 处置

改为 site-data.json 单一真相源，脚本统一生成。

RESULT · 结果

改一次数据，全站同步。

D-2

空板块留下空架子

SYMPTOM · 症状

没有数据的板块仍显示占位与编号断档。

DIAGNOSIS · 诊断

板块显隐写死在 HTML 里。

FIX · 处置

按数据判空隐藏板块，导航编号按可见项重排。

RESULT · 结果

页面始终只展示有内容的部分。

D-3

静态线路拿不到接口

SYMPTOM · 症状

GitHub Pages 下问答与留言不可用。

DIAGNOSIS · 诊断

GitHub Pages 没有 Functions。

FIX · 处置

前端按域名自动切换 API 线路到 pages.dev。

RESULT · 结果

备用线路也能调用边缘函数。
