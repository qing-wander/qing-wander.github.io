本地 http 预览，别用 file:// 直接双击
怎么判断一个模型能不能当桌宠：① 有没有 idle 这类循环待机动作（没有就只能站着不动）； ② 有没有可以表达「对 / 不对 / 思考」的动作（Xbot 的 agree 点头、headShake 摇头就是干这个的）； ③ 体积能不能压在 3MB 以内（手机首屏等不起）；④ 造型在小尺寸下还认不认得出。
被排除的：kira.glb（整间卧室 + IK 少女，场景化，不是干净角色）、 readyplayer.me.glb（写实西装男，0 段动画，要接 Mixamo 重定向才能动）、 duck.glb（Draco 压缩，当前链路加载会卡住）、bath_day.glb / dungeon_warkarma.glb（都是场景）。
